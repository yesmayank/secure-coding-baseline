# Go (net/http, Gin, Echo) — Misconfigurations & Common Vulnerabilities

Defensive reference for Go HTTP services.

---

## Misconfigurations

### 1. Serving `http.Dir(".")` or project root

**What:** `http.FileServer(http.Dir("."))` exposes source, go.mod, and config over HTTP.

**Fix:** Serve only a dedicated `static/` dir; keep secrets out of served paths.

**Detection:** `rg -n "http.Dir|http.FileServer|Static(" *.go`

---

### 2. Verbose error responses / panic in handlers

**What:** `http.Error(w, err.Error(), 500)` or an unhandled panic returns internal details (paths, SQL errors).

**Fix:** Log full error server-side; send generic message. Use `recover` middleware.

**Detection:** `rg -n "http\.Error\(w, err\.Error|fmt\.Fprint.*err\.Error|c\.String\(.*err" *.go`

---

### 3. `html/template` vs `text/template` misuse

**What:** `text/template` does not auto-escape → XSS. Using it for HTML output is unsafe.

**Fix:** Use `html/template` for HTML; `text/template` only for non-HTML.

**Detection:** `rg -n "text/template" *.go`

---

### 4. CORS allow-all

**What:** `Access-Control-Allow-Origin: *` with credentials.

**Fix:** Allowlist origins; credentials only with explicit origins.

**Detection:** `rg -n "Access-Control-Allow-Origin|AllowOrigins|cors" *.go`

---

### 5. Exposed pprof / debug endpoints

**What:** `import _ "net/http/pprof"` registers `/debug/pprof` on the default mux — leaks goroutines, heap, source.

**Fix:** Register pprof only on an internal listener; never on the public mux in prod.

**Detection:** `rg -n "net/http/pprof|debug/pprof|expvar" *.go`

---

## Common Vulnerabilities

### 6. SQL injection via string concatenation

**What:** `fmt.Sprintf("... WHERE id = %s", id)` passed to `db.Query`.

**Fix:** Use `db.Query("... WHERE id = ?", id)` or `QueryRow(..., args...)`.

**Detection:** `rg -n "Sprintf\(.*WHERE|db\.Query\(.*\+|Exec\(.*\+" *.go`

---

### 7. Command injection

**What:** `exec.Command("sh", "-c", "convert "+name)` runs a shell with user input.

**Fix:** Use `exec.Command("convert", name)` (no shell); validate input.

**Detection:** `rg -n "exec\.Command\(\"sh\"|exec\.Command\(\"/bin/sh\"|CommandContext" *.go`

---

### 8. Path traversal in file serving

**What:** `filepath.Join(base, r.URL.Path)` does not stop `..` reliably across sanitizers.

**Fix:** `filepath.Clean`, then verify result is within base; use `http.ServeFile` with a fixed root and reject `..`.

**Detection:** `rg -n "filepath\.Join\(.*r\.URL|os\.Open\(.*r\.URL|ServeFile\(.*r\.URL" *.go`

---

### 9. SSRF via `http.Get(userURL)`

**What:** Outbound HTTP to user URLs hits internal metadata.

**Fix:** Allowlist hosts; resolve and block link-local/RFC1918; validate scheme.

**Detection:** `rg -n "http\.Get\(.*url|http\.Post\(.*url|client\.Do\(.*req" *.go`

---

### 10. Insecure crypto / `math/rand` for tokens

**What:** `math/rand` is deterministic; seeded with predictable values → guessable tokens.

**Fix:** Use `crypto/rand` for tokens, IDs, keys.

**Detection:** `rg -n "math/rand|rand\.Int|rand\.Read" *.go`

---

### 11. Deserialization / gob on untrusted data

**What:** `gob.Decode` of untrusted input can trigger panics or unwanted type instantiation.

**Fix:** Avoid gob for untrusted input; use JSON with strict structs.

**Detection:** `rg -n "gob\.NewDecoder|gob\.Decode" *.go`

---

### 12. Goroutine leaks / unbounded concurrency

**What:** Spawning a goroutine per request without limits → memory/DoS.

**Fix:** Use a bounded worker pool or semaphores; set timeouts on `http.Server`.

**Detection:** review `go func` in request handlers; check `http.Server{}` for `ReadTimeout`/`WriteTimeout`.

---

## Checklist

- [ ] File server scoped to `static/`
- [ ] Generic error messages; recover middleware
- [ ] `html/template` for HTML
- [ ] CORS allowlist explicit
- [ ] pprof/expvar on internal listener only
- [ ] Parameterized SQL
- [ ] No shell with user input
- [ ] File paths bounds-checked
- [ ] Outbound HTTP allowlisted
- [ ] `crypto/rand` for tokens
- [ ] No gob on untrusted data
- [ ] Server timeouts set; bounded concurrency

## Quick detection bundle

```bash
rg -n "http.Dir|http.FileServer|Static\(" *.go
rg -n "http\.Error\(w, err\.Error" *.go
rg -n "text/template" *.go
rg -n "net/http/pprof|debug/pprof|expvar" *.go
rg -n "Sprintf\(.*WHERE|db\.Query\(.*\+|Exec\(.*\+" *.go
rg -n "exec\.Command\(\"sh\"|exec\.Command\(\"/bin/sh\"" *.go
rg -n "math/rand|rand\.Int|rand\.Read" *.go
```
